Características Implementadas:

  1. Carga de archivos Excel: Soporta .xls, .xlsx y .csv
  2. Análisis de tipos de datos: Detecta automáticamente:
    • String (Texto)
    • Integer (Números enteros)
    • Float (Números decimales)
    • Date (Fechas en múltiples formatos)
    • Boolean (Verdadero/Falso)
    • Empty (Celdas vacías)
    • Mixed (Tipos inconsistentes)
  3. Límites: Máximo 20 columnas (A-T), comienza en A1
  4. Interfaz: Tabla interactiva con colores para cada tipo
  5. Estadísticas: Resumen de análisis (total celdas, filas, columnas)
  6. Exportación: Descargar resultados en CSV

Detección de Tipos:

Tipo Ejemplos Detecta
String "Nombre", "Texto" Cualquier texto normal
Integer 123, 456, 789 Números enteros
Float 123.45, 678.90 Números decimales
Date 01/01/2020, 2020-01-01 Múltiples formatos de fechas
Boolean TRUE, FALSE, SI, NO Valores lógicos
Empty (vacío) Celdas sin contenido
