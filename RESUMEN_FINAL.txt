## 🎯 FUNCIONALIDAD

### Qué Hace
```
Lee archivos Excel desde A1 (máximo 20 columnas)
Analiza cada celda detectando el tipo de dato
Muestra resultados en tabla colorida
Permite exportar en CSV
```

### Tipos Detectados
```
📝 String    - Texto
🔢 Integer   - Números enteros
📊 Float     - Números decimales
📅 Date      - Fechas (múltiples formatos)
✓ Boolean    - Verdadero/Falso
⬜ Empty     - Celdas vacías
❌ Mixed     - Tipos inconsistentes
```
