Eliminar Litigantes

Elimina registros de litigantes del sistema mediante archivo Excel

⚠️ ADVERTENCIA: Operación Irreversible

Esta acción eliminará permanentemente los registros de litigantes.

Los datos eliminados NO se pueden recuperar. Asegúrese de tener respaldos antes de continuar.

Subir Archivo para Eliminar Litigantes
Formatos soportados: Excel (.xlsx, .xls) y CSV (.csv) | Tamaño máximo: 50 MB
Requisitos del Archivo
Estructura del Excel:
  • Primera fila debe contener encabezados
  • Una columna con números de documento
  • Sin celdas combinadas
  • Documentos sin guiones ni puntos
Columnas Requeridas:
  • Número de documento (obligatorio)
  • Nombre (opcional, para verificación)
  • Expediente (opcional, para verificación)
Solo se requiere el número de documento para eliminar
Sin Recuperación

Los registros eliminados no se pueden recuperar. Esta operación es permanente.

Registro de Auditoría

Se mantiene un registro de auditoría de todas las eliminaciones realizadas.

Verificación

Sistema verifica que los registros existan antes de proceder con la eliminación.
